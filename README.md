# qwerttclients — универсальная платформа бронирования

Рабочий сайт по дизайн-канвасу «qwerttclients — универсальная платформа бронирования v2»:
рестораны и кафе, салоны и клиники, отели, спорт и коворкинг, мероприятия.
Сделана десктопная версия (контейнер 1200 px, минимальная ширина окна 1240 px).

Проект самостоятельный и не связан с кодом в `apps/` и `packages/` уровнем выше.

## Запуск

Нужен Node.js 24+.

```bash
npm install
npm run dev        # API на http://127.0.0.1:4000, сайт на http://localhost:5180
```

Запуск одной командой без dev-сервера (сервер сам отдаёт собранный фронтенд):

```bash
npm run build
npm start          # http://127.0.0.1:4000
```

Проверки:

```bash
npm test           # 22 интеграционных теста API
npm run typecheck
```

## Что внутри

| Папка | Содержимое |
|---|---|
| `server/` | API на Fastify, база SQLite (`node:sqlite`, файл `data/qwerttclients.db`) |
| `shared/` | Типы, даты и расчёт цен — общие для сервера и фронтенда |
| `web/` | Фронтенд: React, React Router, Vite |
| `web/src/styles/base.css` | Стили дизайн-системы, перенесены из макета без изменений |
| `web/src/icons.generated.ts` | Иконки (Lucide, ISC) и иллюстрации из макета |
| `web/public/photos/` | 50 фотографий мест с Unsplash (лицензия Unsplash), список и авторы — `web/src/photos.ts`, страница /credits |

Экраны: главная, категории, поиск с фильтрами и картой, страница места, бронирование для пяти
типов мест, данные гостя, подтверждение, вход, регистрация, сброс пароля, профиль, мои брони,
детали брони (перенос, смена гостей, отмена, экспорт в календарь), сохранённые места,
уведомления, настройки, кабинет бизнеса, справка.

Дополнительно:

- **Языки:** английский, русский, узбекский (латиница) — весь интерфейс, каталог мест, даты, склонения
  и сообщения сервера. Переключатель в шапке и в настройках; у вошедшего пользователя выбор хранится в аккаунте.
  Словари — `web/src/locales.ru.ts`, `web/src/locales.uz.ts`.
- **Тема «день / ночь»:** переключатель в шапке и в настройках; по умолчанию — как в системе.
- **Анимации:** заставка при первом открытии сайта за сессию, появление страниц, «волна» и нажатие
  у кнопок, подъём карточек, всплывающие окна. При системной настройке «уменьшить движение» анимации отключаются.
- **Аккаунт:** фото профиля (уменьшается до 256 px), двухэтапный вход по коду из приложения-аутентификатора (TOTP).
- **Поиск:** «Рядом со мной» — сортировка по расстоянию от вашего местоположения.
- **Место:** просмотр всех фото, полное меню, лист ожидания для полностью занятого дня
  (при отмене брони ожидающие получают уведомление).
- **Страницы:** о компании, контакты с формой, заявка на подключение заведения, приложения, вакансии,
  пресса (логотип и цвета), блог, условия, конфиденциальность, cookies.
- **Кабинет бизнеса:** обзор дня, календарь недели, брони, гости, отзывы, настройки площадки
  (описание, часы, правила отмены, мгновенное подтверждение, цены, число столов).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `4000` | Порт API |
| `HOST` | `127.0.0.1` | Адрес, на котором слушает сервер |
| `DB_PATH` | `data/qwerttclients.db` | Файл базы |
| `SESSION_IDLE_MIN` | `30` | Через сколько минут бездействия истекает сессия |
| `DEMO_LOAD` | `1` | Имитация броней, сделанных мимо сайта (чтобы часть слотов была занята). `0` — отключить |
| `SEED_DEMO` | `1` | Создавать демо-аккаунты и демо-брони в пустой базе. `0` — отключить |
| `NODE_ENV` | — | `production` включает secure-cookie и убирает ссылку сброса пароля из ответа API |

## Ограничения

- **Почта и SMS не подключены.** Письма с подтверждением не отправляются. Ссылка сброса пароля
  вне production показывается прямо на странице и пишется в лог сервера. Напоминания приходят
  в раздел «Notifications» на сайте.
- **Оплаты нет.** Бронь бесплатна, цена показывается как «pay at the venue». Шаг «Pay» из макета
  мероприятий заменён на «Confirm».
- **Вход через Google и Apple не настроен:** кнопки есть, при нажатии сообщают об этом.
- **Каталог — демонстрационные данные** в `server/catalog.ts` (15 мест в Ташкенте). Места из макета
  сохранены; кафе, коворкинг и часть меню и услуг добавлены, чтобы работали все категории.
- **Карта схематичная:** иллюстрация из макета с примерными позициями, ссылка «Open in Google Maps»
  ведёт на настоящую карту.
- **Мобильная и планшетная версии не делались** (макеты 27–38).
- **Мобильных приложений нет:** кнопки App Store и Google Play ведут на страницу «скоро».
- **Обращения и заявки** с форм «Контакты» и «Подключить заведение» сохраняются в базе
  (`contact_messages`, `partner_requests`); интерфейса для их просмотра пока нет.
- **Тексты, которые площадка правит в кабинете** (описание, правила), показываются как есть,
  без перевода на другие языки.
- Часовой пояс площадок — Ташкент (UTC+5).
